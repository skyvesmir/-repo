# 定期実行と、前回の続き

SKILL.md §9 の詳細。定期実行のとき、または対話で前回の整理案やログを指す依頼（「D2 と R3 を進めて」など）を受けたときに読む。状態ブロックの形式は `references/templates.md` §3。

## 目次

1. 前回の状態を読む
2. 差分の調べ方
3. 定期実行で実行してよい範囲
4. 対話で前回の続きを扱う
5. 全体の再調査

---

## 1. 前回の状態を読む

1. ログ用フォルダ（ユーザー指定がなければマイドライブ直下の `_drive-organizer-logs`）の子を、`excludeContentSnippets: true` で取る。ログが多いときは `createdTime` で最近のものに絞る。
2. タイトルの日時（`YYYY-MM-DD_HHmm`）が最も新しいログを選び、それ 1 件だけを `read_file_content` で読む。
3. 先頭の状態ブロックを使う。読み取り用の表現ではバックスラッシュが付くので（`\_` `\-` など）、ファイル ID やパスはそれを外してから使う。
4. ログ用フォルダがない、ログがない、状態ブロックが読めない場合は、そう明記し、範囲を絞った初回の調査として扱う。存在しない履歴を推測しない。

## 2. 差分の調べ方

- **基準時刻**: 前回の状態ブロックの `last_scan`（前回の実行を開始した時刻）。今回の実行を開始した時刻を最初に控え、今回のログの `last_scan` にする（実行中に作られたファイルを次回に取りこぼさないため）。
- **差分の検索**: `owner = 'me' and (modifiedTime > '前回の last_scan' or createdTime > '前回の last_scan')`（`excludeContentSnippets: true`、pageSize 30）。アップロードされたファイルは元の更新日時を保つので、`createdTime` も条件に入れる。
- **範囲の判定**: 結果の `parentId` が、状態ブロックの `scope`・`vaults` のフォルダか、この実行で既にわかったフォルダかを確かめる。わからなければ親をたどり、既知のフォルダに着くかで判定する。たどった結果は実行中に覚えておき、同じフォルダを二度たどらない。`excluded_folders` とログ用フォルダの中のものは除く。
- **優先して扱うもの**:
  1. 範囲内の新規・変更ファイル
  2. それらと同名・同じ基本名の既存ファイル（基本名で `title contains` をまとめて検索する）
  3. 前回の `open_items`（要確認）と `pending`（承認待ち）。まだ存在するか、変わっていないかを確かめる
- **繰り返さないもの**:
  - `declined`（却下された提案）
  - `reviewed`（検討して維持と決めた組）。記録した更新日時より新しくなったファイルがあるときだけ再検討する
- 差分の外で気づいた既存の問題は報告に書くが、調査は広げない。
- 本文の読み取りが上限（SKILL.md §3）を超えた分は、`open_items` に持ち越す。

## 3. 定期実行で実行してよい範囲

- 原則として提案のみとし、整理案をログに書く。
- タスクの指示でユーザーが事前に承認した種類の操作だけ、確度「高」のものに限って実行してよい。
- 事前承認があっても、次は実行しない。見る人がいない状態で行うと取り消しにくく、リンク切れにも気づけないため。
  - ゴミ箱への移動
  - Vault 内のファイルの改名・移動
  - Frontmatter の適用
- ログは毎回、新しいファイルとして保存する（SKILL.md §8）。

## 4. 対話で前回の続きを扱う

- ユーザーが前回の整理案の ID を指したら、最新ログ（またはそのとき保存した整理案）を読み、ID が指すファイル ID と操作の詳細を確かめる。見つからない、または曖昧なら、推測で実行せずに尋ねる。
- 実行の前には SKILL.md §6-2 の事前確認を行う。ログの時点（`planned_modified`）から変わっていれば、その項目は実行しない。
- 承認・却下の結果は、新しいログとして 1 件書く。実行した項目は `pending` から外し、却下された項目は `declined` に移す。

## 5. 全体の再調査

差分だけでは見つからない重複（離れたフォルダにある同じサイズのファイル、名前を変えた複製など）がある。`last_full_scan` から 1 か月程度たったら、全体の再調査を提案する。
